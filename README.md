# 2026년 독일 BK 연구교류 출장 사전 설문 (한양대학교 대학원전략처 대학원전략팀)

교수님들이 4개 항목에 답하고 연구 소개 자료(PPTX/PDF)를 올리는 설문 페이지입니다.
GitHub Pages에 올리고, 응답은 구글 시트·드라이브에 저장됩니다.

```
index.html            설문 + 관리자 화면 (주소 끝에 #admin)
apps-script/Code.gs   구글 Apps Script 백엔드 (GitHub에 올리지 않아도 됨)
assets/logo.png       (선택) 학교 공식 로고 파일을 넣으면 상단에 표시
```

---

## 1단계 · 구글 시트와 Apps Script 준비 (약 5분)

1. 구글 드라이브에서 **새 스프레드시트**를 만들고 이름을 정합니다. 예) `2026 독일 BK 사전설문 응답`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.

## 2단계 · 관리자 비밀번호 설정

1. `Code.gs`의 `setPassword` 함수 안 `'여기에-관리자-비밀번호'`를 원하는 비밀번호로 바꿉니다.
2. 위쪽 함수 선택 칸에서 `setPassword`를 고르고 **실행**을 누릅니다.
   - 처음 실행하면 권한 승인 창이 뜹니다. 본인 계정 선택 → ‘고급’ → ‘(안전하지 않음)으로 이동’ → 허용.
3. 실행이 끝나면 **비밀번호 값을 다시 지우고 저장**하세요. 비밀번호는 ‘프로젝트 설정 → 스크립트 속성’에 따로 보관됩니다.
   - 나중에 비밀번호를 바꿀 때도 같은 방법으로 다시 실행하면 됩니다.

### (선택) 안내 메일 설정

- `setPassword` 안의 `REPLY_TO`에 팀 공용 메일을 넣으면, 교수님이 안내 메일에 답장할 때 그 주소로 갑니다.
- `NOTIFY_EMAIL`에 담당자 메일을 넣으면, 제출될 때마다 안내 메일 사본을 숨은참조로 받습니다.
- 함수 선택 칸에서 `testMail`을 실행하면 안내 메일 예시가 내 메일로 옵니다. 처음 실행할 때 **메일 발송 권한**을 한 번 더 승인해야 합니다.
- 메일은 스크립트를 배포한 구글 계정의 Gmail에서 나갑니다. 하루 발송 한도는 일반 Gmail 100통, 학교·기업용 Google Workspace 계정 1,500통입니다.

## 3단계 · 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(톱니바퀴) → **웹 앱**
3. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로 유지됩니다.

## 4단계 · index.html에 URL 붙여 넣기

`index.html` 아래쪽에서 이 줄을 찾아 따옴표 안에 URL을 넣습니다.

```js
const SCRIPT_URL = "https://script.google.com/macros/s/....../exec";
```

비워 두면 **미리보기 모드**로 동작합니다(제출해도 저장되지 않고, 관리자 화면에 예시 응답이 보임).

## 5단계 · GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. 예) `hy-research-survey`
2. **Add file → Upload files**로 `index.html`(그리고 로고가 있으면 `assets/logo.png`)을 올립니다.
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/hy-research-survey/` 주소가 생깁니다.

- 교수님들께 보낼 주소: `https://<아이디>.github.io/hy-research-survey/`
- 관리자 주소: `https://<아이디>.github.io/hy-research-survey/#admin`

## 운영 메모

- **응답 확인**: 관리자 화면에서 집계·상세·CSV를 볼 수 있고, 구글 시트 ‘응답’ 탭에도 그대로 쌓입니다.
- **첨부파일**: 드라이브의 `2026 독일 BK 사전설문 첨부파일` 폴더에 `성명_단과대학_학과_연구소개.pptx` 이름으로 저장됩니다. 관리자 화면의 ‘열기’ 링크는 시트 주인 계정으로 로그인했을 때 열립니다.
- **접수번호·안내 메일**: 제출하면 `BK2026-001`부터 순서대로 접수번호가 붙고, 교수님 이메일로 접수 내용 요약이 담긴 안내 메일이 자동으로 갑니다. 발송 결과는 시트의 ‘안내메일’ 열에 남습니다(`발송 …` 또는 `실패: …`). 메일이 실패해도 접수 자체는 저장됩니다.
- **수정**: 교수님이 같은 이메일로 다시 제출하면 기존 응답이 갱신되고 ‘수정 횟수’가 올라갑니다. 접수번호는 바뀌지 않고, ‘수정 접수’ 안내 메일이 다시 갑니다. 작성 중인 내용은 교수님 브라우저에 자동 임시 저장됩니다.
- **방문 기관·마감일·문의처**: 관리자 화면 ‘설문 안내 정보’에서 바꾸면 설문 상단에 바로 반영됩니다. 비워 두면 마감 `2026.10.22.(목) 오후 5시`, 문의 `대학원전략처 대학원전략팀`이 보입니다.
- **소속 목록**: 단과대학·학과 목록은 `index.html` 안의 `const DEPTS = {...}` 한 줄에 들어 있습니다. 학과를 추가·수정할 때 이 부분만 고치면 됩니다. 목록에 없는 소속은 ‘기타 (직접 입력)’으로 적을 수 있습니다.
- **보안**: 비밀번호는 GitHub 코드에 들어가지 않고 Apps Script 서버에서만 확인합니다. 10분 동안 10번 틀리면 10분간 잠깁니다. 저장소가 공개(Public)여도 응답은 비밀번호 없이 볼 수 없습니다. 다만 설문 주소를 아는 사람은 누구나 제출할 수 있으니 주소는 교수님들께만 보내 주세요.
- **색상·로고**: 상단 색은 한양블루 근사값입니다. 디자인경영센터(02-2220-1541) UI 가이드의 공식값으로 바꾸려면 `index.html` 맨 위 `--hy-blue` 값을 고치면 됩니다. 공식 로고는 디자인경영센터와 협의 후 `assets/logo.png`로 넣어 주세요.
